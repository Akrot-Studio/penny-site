# penny.akrot.app — notes for Claude

Penny's product website: `site/` built by `node tools/build-site.js` into `dist/site`, plus Cloudflare Pages Functions in `functions/`
(newsletter and the app's `/api/redeem`, which must keep working: the app depends on it). See `README.md` for layout and the release routine.
App facts come from the app repo (`../penny`, `penny-source`): `docs/`, `CHANGELOG.md`, `package.json`. Brand: `../akrot/brand/BRAND.md`.

## Rules
- `app/` is generated by `tools/sync-from-app.js`; never edit it by hand.
- The build fails on stale release headlines and on any GitHub link. Fix the page; never weaken the check.
- Don't invent ratings, download counts, quotes or features the app doesn't have.
- Deploys, DNS, GitHub repos, Cloudflare settings and anything public happen only when the owner asks. Never handle API tokens or secrets.
- Verify in a real browser at phone (>=320 px) and desktop widths before reporting.
